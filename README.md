# Roamly — Travel & Tourism Platform

A responsive, interactive travel planning prototype created for a software engineering project review.

## Open the website
Open [index.html](index.html) in a browser. It is a static site with no build step.

## Features
- Browse three sample destination cards and add an idea to your itinerary.
- Enter custom activities and estimated costs; the budget total updates automatically.
- Remove itinerary items and see the count and estimate recalculate.
- Save the itinerary in the current browser using localStorage.
- Search for a destination to navigate to discovery and show demo feedback.
- View illustrative local guide profile dialogs.
- Responsive layout for desktop and mobile.

## Demo flow
1. Open the destination section and add an idea.
2. Add a custom activity with an estimated cost.
3. Show the updated budget and activity count.
4. Remove an item, then reload to demonstrate local browser persistence.
5. Open a guide profile dialog.

## Limitations
This is a front-end demonstration. Destinations, estimates, ratings, images, and guide profiles are illustrative. Search is not connected to a travel service. There is no user account, backend, collaborative trip sharing, live inventory, booking, messaging, or payment processing. External Unsplash images require an internet connection.

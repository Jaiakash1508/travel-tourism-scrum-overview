# Roamly — Travel & Tourism Platform

A responsive, interactive front-end concept for discovering destinations and planning trips. Created for a software engineering project review.

## Try the demo
Open [index.html](index.html) in a browser. No build tools or account are needed. The trip planner supports adding/removing activities, sample budget totals, destination ideas, search feedback, and guide profile dialogs. It stores itinerary items in this browser with localStorage.

## Project scope
The original Scrum overview is preserved in [travel-tourism-scrum-overview.html](travel-tourism-scrum-overview.html). It describes the Travel & Tourism Platform backlog and sprint plan. The interactive site is a prototype: destination imagery and guide details are illustrative. Search, pricing, comparisons, bookings, messages, and payments are not connected to live services.

## Main interactions
1. Use the destination cards to add a trip idea.
2. Add a custom activity and estimate; see the trip budget update.
3. Remove activities from the itinerary.
4. Open a sample local guide profile.
5. Search for a place to see the destination section and demo feedback.

## Scrum snapshot
The supplied project overview lists six sprints, fourteen activities, 115 story points, and a 72-day plan. Refer to the original overview for its detailed Scrum breakdown.

## Limitations
This is a client-side demonstration. It has no backend, user authentication, real-time availability, persistent account data, or transactional booking functionality. Unsplash images require an internet connection.
